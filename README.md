# wg-awg-relay

Проект релея WireGuard / AmneziaWG с поддержкой произвольного количества IPv4- и IPv6-подсетей за одним исходящим пиром.

## Архитектура

Разработка ведётся поэтапно:

1. **Библиотека протокола и маршрутизации** — независимые структуры конфигурации WireGuard/AmneziaWG, проверка входных данных, нормализация CIDR, таблица маршрутов IPv4/IPv6, longest-prefix match, детерминированное разрешение конфликтов и потокобезопасное динамическое обновление.
2. **Движок релея** — интеграция библиотеки с сетевым стеком и WireGuard/AmneziaWG-интерфейсом, управление маршрутами без пересоздания туннеля, сохранение состояния NAT.
3. **Программа и CLI** — загрузка конфигурации, команды управления и диагностика.
4. **Тестирование и документация** — unit-, property-based- и интеграционные тесты, включая проверку обновления маршрутов при активных соединениях.

## Принципы

- IPv4 и IPv6 поддерживаются в единой модели.
- Маршруты могут задаваться как внутри `peers[].routes`, так и общим списком `routes`.
- Сначала выбирается наиболее длинный префикс (LPM). Приоритет сравнивается **только между маршрутами с одинаковым префиксом**.
- Обновление таблицы маршрутов не должно требовать пересоздания туннеля.
- Изменение маршрутов не должно сбрасывать уже установленные NAT-сопоставления.
- Библиотека не привязана к CLI и может использоваться отдельно.

## Статус

Ведётся реализация первого этапа — библиотеки протокола и маршрутизации. До завершения интеграции с сетевым движком поддержка реального обмена WireGuard/AmneziaWG-пакетами не заявляется.
